# PM 系统索引 (Memory Bank)
> LinguaFlow 的项目管理中枢。新人 / 外包 / 未来的你，从这里开始。

## 你怎么开始一个需求？
1. 读 `site-setup.md` —— 确认它现在是什么、边界在哪。
2. 新想法先写进 site-setup 第 7 节「待立项候选」（提案，非需求）。
3. 立项时补全规格，再开 `tasks/linguaflow-tasklist.md` 拆任务。
4. 按任务构建，过 `PM-METHODOLOGY.md` 的质量门。
5. 周五 30 分钟复盘（见方法论 §6）。

## 文件地图
| 文件 | 作用 |
| --- | --- |
| `site-setup.md` | 唯一事实来源：规格 / 现状 / 边界 / 候选 |
| `tasks/linguaflow-tasklist.md` | 当前任务清单（勾选式看板） |
| `PM-METHODOLOGY.md` | PM 方法论 + 1–2 人团队管理手册 |
| `README.md` | 本索引 |
| `../agents/pm.md` | PM 操作程序（专家如何拆任务） |

## 铁律
- 提案 ≠ 需求。候选区未批准不进任务。
- 改需求先改 site-setup，再改任务。
- 知识不锁脑：实质改动写 memory 日记。
