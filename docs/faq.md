# 已知限制与常见问题

> 踩坑前先看这里。
>
> 返回 [README](../README.md)。

**Q1：为什么不同语言的发音听起来不一样？**
这是有意的**语种门控**：英文单词走有道 `dictvoice` 真人词典音（免费、无需 Key）；日语单词固定走浏览器 Web Speech `ja-JP`；中文、韩语及其余语言的朗读优先走 Qwen `qwen3-tts-flash`，没有 Qwen Key / 未授权 AI / 请求失败时回落到浏览器 Web Speech。详见 [AI 与语音能力](./ai-voice.md)。

**Q2：录音识别（STT）还能用吗？**
不能。STT / Paraformer 相关代码已移除，项目明确不再恢复该功能。

**Q3：我的数据安全吗？请说清楚有哪些对外请求。**

| 数据 | 放在哪 | 会不会外发 |
| --- | --- | --- |
| 学习进度、词汇、收藏、书籍 | 浏览器 localStorage / IndexedDB | 默认不外发；**线上版登录后可手动/自动开启云端同步**到自己的账号 |
| API Key | 你在「模型设置」填写，存在本机 localStorage | 调用模型时随请求发出；线上版经本站服务器中转（白名单域名、服务器不存储 Key）。开启云端同步时，模型配置会随备份一起同步到账号以便在其它设备恢复 |
| AI 对话内容 | 服务端日志 | 按合规要求留痕 **180 天**（只含对话文本与模型名） |
| 音频缓存 | IndexedDB（`linguaflow-tts`） | 纯本地，不上传 |

- **生产构建不内置任何 Key**；前端直连模式意味着 Key 在浏览器端可见，本地自用无妨，公网部署务必使用自己的 Key。
- 线上版提供同源 `/api` 反代，避免浏览器直连厂商的 CORS 问题；服务器自身没有大模型密钥。
- 首次触发 AI 调用会弹窗说明并取得授权，「模型设置」里可随时关掉；关闭后相关功能走本地兜底。
- 详见 [隐私说明](./privacy.md) 与 [AI 与语音能力](./ai-voice.md)。

**Q4：能换模型吗？**
不用改代码。进「我的资料 → 模型设置」即可切换 GLM / Qwen / OpenRouter / DeepSeek / 自定义 OpenAI 兼容端点，并可按学习环节指定「快模型 / 高推理」。本地开发也可通过 `.env` 覆盖默认模型名。

**Q5：没配 API Key 还能用吗？**
能。词库 A1 起步词、日语五十音打字专项、书架阅读、SRS 复习、错题本、本地兜底任务等都不依赖 AI。AI 相关功能在首次调用时会提示你填写自己的 Key。

**Q6：切换学习语言后，之前的任务 / 进度会串吗？**
不会。今日任务缓存与今日产出线均按「日期 × 语言」分别保存；每门语言的 XP、等级、连胜独立计算，同一天完成两门语言的产出线只加一次连胜。
