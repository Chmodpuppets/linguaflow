# LinguaFlow 隐私政策

> 本政策为草稿，正式上线前请核对并补充联系方式。适用：LinguaFlow 线上版（含开源版自托管者）。

## 一、我们收集哪些信息

| 类别 | 内容 | 说明 |
|---|---|---|
| 账号信息 | 用户名、密码 | 密码使用不可逆哈希（scrypt）加密存储，绝不存明文 |
| 学习数据 | 学习进度、写作、词汇、错题、书籍等 | 线上版存服务器；开源版仅存你本机浏览器 |
| 合规对话日志 | 用户提问与 AI 返回内容 | 依《网络安全法》等法律法规要求留存不少于 6 个月 |
| 错误日志 | 崩溃信息、页面地址、浏览器信息 | 仅用于排查故障，不关联到具体个人 |
| 反馈信息 | 你主动提交的反馈内容（含选填联系方式） | 仅用于回复与改进 |

## 二、我们如何使用

- 提供学习与「学习搭子」社区服务、跨设备数据同步
- 排查故障、改进产品
- 履行法律法规规定的义务（如对话日志留存）

## 三、存储与期限

- 学习数据：随账号存续保存，账号注销即删除
- 合规对话日志：至少保存 6 个月（法定义务）；账号注销后，日志中的用户标识将被匿名化，内容依法保留
- 错误日志、反馈：用于改进产品，可随时申请删除

## 四、你的权利

你可以随时：

- **查询、导出**你的学习数据
- **更正、删除**你的数据
- **注销账号**（应用内「学习搭子 → 账号与反馈 → 注销账号」），注销后服务器端账号与学习数据将被删除

## 五、数据安全

- 密码不可逆哈希存储，登录限流防暴力破解
- 生产环境通过 HTTPS 加密传输
